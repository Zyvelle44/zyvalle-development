# Zyvalle Development — Black & White Portfolio

A readable, responsive portfolio for a professional web developer. Built with plain HTML, CSS, and JavaScript; includes subtle reveal animations, a scroll progress bar, and mobile navigation.

## Publish free with GitHub Pages

1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, `favicon.svg`, and `.nojekyll` to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After deployment, visit `https://YOUR-USERNAME.github.io/`.

## Customize before launch

- Replace `https://discord.com/` in `index.html` with your Discord profile link, if you want direct contact.
- The Join Server button currently uses `https://discord.gg/xxX3d3Akb8`. Replace it if your invite changes.
- Send your own project screenshots to replace the clearly marked image placeholders.
- Update the list of technologies to match the tools you actively use and want to offer.
- The contact links open Discord; no paid backend or database is required.

## Notes

This is a static site and needs no paid hosting, PHP server, database, or build step. Google Fonts is optional; remove the Google Fonts links in `index.html` to use system fonts only.


## SEO setup

The site includes a descriptive title and meta description, social sharing metadata, `robots.txt`, `sitemap.xml`, structured data describing Zyvalle Development, semantic service headings, and a visible FAQ section.

Before publishing:
1. Replace `YOUR-USERNAME` in both `sitemap.xml` and `robots.txt` with your GitHub username.
2. Once the website is live, add the exact website URL as a property in Google Search Console and submit `/sitemap.xml`.
3. Use Search Console's URL Inspection tool to request indexing after publishing.
4. Keep the portfolio descriptions accurate, add real project details, and include your actual contact/profile links.
5. If you later use a custom domain, update the sitemap and add a canonical URL for that domain.

SEO cannot guarantee a top ranking or that the site appears for every search. Google chooses whether and where to show a page based on relevance, competition, crawlability, and other signals. Indexing can take time.
